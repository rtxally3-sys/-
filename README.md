# ホシフダ物語

iPhone の Safari で遊べる、カードバトルRPGです。
フィールドを歩いて、人に話しかけてカードバトル。勝ってお金をため、パックを買ってデッキを強くし、ボスをたおして先へ進みます。

- カード・キャラクター・絵はすべてオリジナル（絵はコードで描いています）
- インストール不要。ページを開くだけで遊べます
- 進み具合は自動で iPhone の中に保存されます

## 遊び方

公開（GitHub Pages）を有効にすると、次のアドレスで遊べます。

```
https://<GitHubのユーザー名>.github.io/<このリポジトリ名>/
```

### GitHub Pages を有効にする（最初の1回だけ）

1. このリポジトリのページで **Settings** を開く
2. 左のメニューから **Pages** を選ぶ
3. 「Build and deployment」の Source を **Deploy from a branch** にする
4. Branch を **main**、フォルダを **/ (root)** にして **Save**
5. 数分待つと、同じ画面の上のほうに公開アドレスが表示されます

### iPhone のホーム画面に置く（おすすめ）

Safari でゲームを開く → 共有ボタン（□に↑）→ **「ホーム画面に追加」**。
アプリのように全画面で遊べて、セーブデータも消えにくくなります。

> 注意：Safari で遊んだデータと、ホーム画面から開いたときのデータは別々に保存されます。
> 引っこすときは、ゲーム内の「せってい → バックアップ」で書き出し／読みこみができます。
